# 椰奶群管（astrbot_plugin_yenai_group_admin）

把 Yunzai 的 **椰奶群管**（`yenai-plugin/apps/groupAdmin`）1:1 复刻到 AstrBot，
命令统一使用 AstrBot 全局触发词（本机已配置为 `-`）。

## 功能

- 基础群管：禁言（自定义时长/单位）、解禁、全体禁言、踢人、踢黑、设置/取消管理、
  修改/申请头衔、禁言列表、解除全部禁言、发通知、加精/移精、自我禁言。
- 清理排行：查看/清理“从未发言的人”“N 天没发言的人”，不活跃排行榜，最近入群记录。
- 定时禁言/解禁：支持 `HH:MM` 与 cron 表达式（兼容 Quartz 的 `?` 写法），重启后自动恢复。
- 违禁词：精确/模糊/正则 匹配，踢/禁/撤/踢撤/禁撤/踢黑 六种处罚，头衔屏蔽词。
- 黑白名单：白名单豁免、白名单自动解禁、黑名单入群拒绝 + 入群即踢 + 群内发言即踢。
- 投票：投票禁言/踢人、跟票、管理员一票否决、参数在线调整。
- 入群验证：算式验证 / 字母验证码（私聊下发）、超时踢出、最后一分钟提醒、精确/模糊模式、
  重新验证、绕过验证。
- 群公告：发/查/删群公告（依赖协议端 `_send_group_notice` 系列接口）。
- 私聊群管：`-禁言 群号 QQ 时长`、`-解禁 群号 QQ`、`-全体禁言 群号`、`-踢 群号 QQ`。

完整指令列表见群内 `-群管帮助`。

## 与椰奶的已知差异

- 不含群数据类功能：龙王、群星级、群数据、今日打卡、群发言榜（依赖 QQ 网页截图/私有接口）。
- 违禁词的 `{image...}` / `{face...}` 只按纯文本匹配，不做图片/表情实体化。
- `join_time` / `last_sent_time` 等非标准字段缺失时，直接提示“当前协议端不支持此功能”。
- 禁言列表优先读协议端字段，缺失时用插件本地登记的禁言补充。
- 入群验证状态存内存，插件重启后丢失（与椰奶一致）。
- 字母验证码为 AstrBot 版新增（椰奶只有算式验证）：验证码私聊下发，用户在群内回复完成验证，
  不区分大小写；私聊走协议端的群临时会话（`send_private_msg` 带 `group_id`），
  完全发不出去时自动回退为算式验证。

## 安装

把整个目录放到 `AstrBot/data/plugins/astrbot_plugin_yenai_group_admin/` 后重载插件。

> ⚠️ 本插件的所有指令都按全局触发词 `-` 编写（例如 `-禁言 @某人 10分`）。
> 如果你的 AstrBot 仍是默认触发词 `/`，需要先把全局配置的 `wake_prefix` 改成 `-`
> （或改成同时包含 `-`），否则所有指令都不会被匹配到。

## 数据

- 每群配置：`data/plugin_data/astrbot_plugin_yenai_group_admin/groups/<群号>.json`
  （违禁词、禁用词禁言时长、头衔屏蔽词、验证开关、验证类型/模式/超时、加群通知开关、本地禁言记录）。
- 定时任务：`data/plugin_data/astrbot_plugin_yenai_group_admin/mute_tasks.json`。

## 依赖

无需额外依赖；定时任务使用 AstrBot 自带的 `apscheduler`。
